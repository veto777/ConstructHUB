## Skipped, limitations, and review clarifications

- No browser screenshots, live OAuth/provider operations, worker interruption, or narrow-viewport/keyboard walkthrough were run: this is the designated Codex lane with no server. Responsive wrapping, overflow containers, labels, focus styles, and shadcn dialog behavior were implemented, but live visual verification remains a filming prerequisite.
- `server/cloudflare/integration.test.ts` requires a disposable development database and creates fixtures. It was not run with an empty DATABASE_URL; route tests instead use mocked database/provider calls. The unrelated pre-existing help-registry `/listing-editor` failure was not changed.
- Table sorting explicitly applies to displayed rows; the overview and its trend query cover the entire selected date window. Google top-row/anonymization/delay caveats remain visible.
- Kimi describes four raw Cloudflare panels because traffic also had a separate readable list. The old loop actually serialized all five datasets, including traffic; all five are replaced.
- There is no DNS editor/preview in the owned Cloudflare screen. Its preview is for edge rule packs. The input-binding fix applies there; the registrar DNS preview belongs to the domains lane.
- The country report links to this site's flagged-IP list. It does not claim a country-filtered IP list: that existing endpoint does not provide a country filter.
- Job status describes retained jobs and completed import timestamps, not guaranteed upstream completeness. Old datasets without retained job history say Not yet recorded rather than inventing a sync time.
