eTRAKiT


The eTRAKiT Self-Service Portal is a space for all developers, contractors, homeowners, business owners, and others to apply for permits, licenses, inspections, planning review, and more. 
To access the portal, click on the image above.

For data valid through April 29, 2026, please use the eGov portal.
For data from April 30, 2026 to current, please use the eTRAKit portal.

To use the County’s eTRAKiT Self-Service Portal, you must create the correct type of account.
Start here:
  • Are you a licensed contractor?
    → You need a Contractor Account 
  • Are you a resident, property owner, or not a licensed contractor?
    → You need a Public User Account 
Please review the "How To" pages listed below for specific topics to learn more about these processes.
For Permit Type Definitions, refer to the page listed below.
