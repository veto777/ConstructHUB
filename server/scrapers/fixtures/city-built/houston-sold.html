Sold Permits Search

Textarea

Select an option below to search for permits sold in a rolling three-year period, or search by council district.

To obtain information about basic permit history, you can use this search option. For a complete history or other records, please contact the Open Records section at 832-394-8800 or houstontx.gov/publicinformation. 

If you feel a project violates deed restrictions, please contact the Office of the City Attorney's Deed Restriction Enforcement Team.

Permit Activity Reports

The Permit Activity Report provides information on new construction, remodeling, and change-of-use permits by ZIP Code to help inform residents about development activity in their neighborhoods.

For additional questions regarding permits, you may contact the Code Enforcement Group at 832.394.9000.
